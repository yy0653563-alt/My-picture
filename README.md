# My-picture

موقع لتوليد الصور بالذكاء الاصطناعي — اكتب وصفاً بالعربية أو الإنجليزية، وسيقوم الذكاء الاصطناعي بإنشاء الصورة فوراً.

## المميزات

- توليد صور مجاناً عبر [Pollinations.ai](https://pollinations.ai) بدون مفاتيح API أو تسجيل
- دعم كامل للغة العربية (واجهة RTL)
- اختيار مقاس الصورة (مربع / عريض / طولي) وعدد الصور المولّدة في كل مرة
- سجل آخر 20 صورة مولّدة محفوظ في المتصفح (localStorage)
- عرض الصورة بالحجم الكامل وتحميلها مباشرة

## التشغيل

الموقع ملفات ثابتة (HTML/CSS/JS) ولا يحتاج أي خادم أو تثبيت:

- **افتح `index.html` مباشرة في المتصفح**، أو
- شغّل خادماً محلياً:
  ```bash
  python3 -m http.server 8000
  ```
  ثم افتح `http://localhost:8000`

## النشر على GitHub Pages

1. ادمج هذا الفرع في `main`
2. من إعدادات المستودع: **Settings → Pages → Source: Deploy from a branch → main / (root)**
3. سيصبح الموقع متاحاً على:
   `https://yy0653563-alt.github.io/My-picture/`
